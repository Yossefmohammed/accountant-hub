Task  Description  
Build  a  web  application  called  Accountant  Hub .  
The  platform  should  allow  accountants  to  find  accounting  jobs  and  submit  bids  to  complete  
those
 
jobs.
 
Required  Features  
1.  Jobs  Listing  Page  
Create  a  page  that  displays  available  accounting  jobs.  
Each  job  card  should  show:  
●  Job  title  ●  Company/client  name  ●  Short  description  ●  Budget  range  ●  Deadline  ●  Job  category  ●  Number  of  bids  received  ●  Posted  date  ●  Status:  Open  /  Closed  

The  page  should  include  basic  filters  such  as:  
●  Search  by  job  title  ●  Filter  by  category  ●  Filter  by  budget  range  ●  Sort  by  newest  /  highest  budget  
2.  Job  Details  Page  
When  the  accountant  clicks  on  a  job,  they  should  see  a  detailed  job  page.  
The  page  should  include:  
●  Full  job  description  ●  Client/company  information  ●  Required  skills  ●  Expected  delivery  time  ●  Budget  ●  Attachments  placeholder,  if  any  ●  Existing  bids  count  ●  Apply  /  Submit  Bid  button  
3.  Submit  Bid  Flow  
As  an  accountant,  I  should  be  able  to  apply  for  a  job  by  submitting  a  bid.  
The  bid  form  should  include:  
●  Proposed  price  ●  Estimated  delivery  time  ●  Cover  letter  /  proposal  message  ●  Relevant  experience  summary  
After  submitting,  the  system  should  save  the  bid  and  show  a  success  message.  
The  same  accountant  should  not  be  able  to  submit  more  than  one  bid  for  the  same  job.  
4.  Basic  Authentication  
Create  simple  authentication  for  accountants.  
Required:  
●  Register  ●  Login  ●  Logout  

●  Only  logged-in  accountants  can  submit  bids  
Admin/client  authentication  is  not  required,  but  you  may  seed  sample  jobs  in  the  database.
